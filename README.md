# Tuition_project
***
## Описание проекта
***
Новая "фича" для личного кабинета клиента крупного банка - виджет, <br/>
который показывает несколько последних успешных банковских операций клиента.<br/>
Это учебный проект студента курса [Python - разработчик](https://sky.pro/courses/programming/python-web-course#giftpopup)
на обучающей платформе [Skypro](https://sky.pro/).
## Структура проекта
***
* src/masks.py - модуль с функциями маскировки реквизитов
* src/processing.py - модуль с функциями сортировки и фильтрации банковских операций
* src/widget.py - модуль с функцией форматирования даты
## Установка
***
Для разработчика:
```commandline
poetry install
```
## Пример использования
***
Для того, чтобы запустить проект, необходимо сначала установить зависимости.<br/>
Затем нужно запустить файл `main.py`:
```commandline
python main.py
```
